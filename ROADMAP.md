# ROADMAP — Ассистент Райя

**Цель проекта:** Создать отличный практический путеводитель по рекрутменту полного цикла + удобный AI-инструменты, которые помогают рекрутерам.

## Общая философия развития

(Обновлено 18 июня 2026 года) Проект развивается в двух направлениях:
- **Райя гид** — контент и методологии (приоритет сейчас)
- **Райя инструмент** — техническая часть и автоматизация (замарожено, не хватает мощностей для продолжения)

## v0.3 — HR-анализ и отчёт (ручной процесс)
**Статус: ✅ Завершено (вручную/облачно)**

Входные данные: Описание вакансии + Резюме кандидата (CV) + Структурированный диалог с кандидатом

Формируется HR-отчёт:
- Общая информация
- Краткое саммари кандидата
- Опыт работы
- Технический стек
- Мотивация к смене работы
- Сильные стороны
- Риски
- Вопросы для следующего этапа
- Итоговая рекомендация: Подходит / Условно подходит / Не подходит

## v0.4 — Автоматизация разметки ролей
**Статус: ✅ Завершено (облачно через API)**

Локальный подход (speaker diarization) исследован и отброшен:
- Pyannote несовместим с PyTorch 2.8 (_pickle.UnpicklingError)
- Локальная разметка через акустический анализ не реализована

Реализован облачный подход (semantic role detection через LLM):
- Скрипт role_tagger.py с поддержкой Groq API и Gemini API
- Модель llama-3.3-70b-versatile (Groq) — качество высокое
- Модель gemini-2.0-flash (Gemini) — качество высокое
- Автоматическое разделение реплик HR / CAND без ручного вмешательства
- Выбор провайдера прямо в Web UI (Groq / Gemini)
- Результат сохраняется в output/interview_roles.txt
- Редактируемое поле для ручной правки результата

# Ассистент Райя — Полноценный путеводитель по рекрутменту + AI-инструментам

**Райя помогает рекрутеру, но не заменяет его полностью.**

---

## О проекте

**Ассистент Райя** — открытый проект, который объединяет два направления:

1. **Райя гид** — полный практический путеводитель по рекрутменту полного цикла (от поиска кандидата до онбординга).
2. **Райя инструмент** — AI-инструменты, которые автоматизируют рутинные задачи рекрутера.

Проект разрабатывается с любовью к профессии и с твёрдой верой в то, что **искусственный интеллект должен быть отличным помощником, а не заменой человеку**.

Основной фокус — IT-рекрутмент, но принципы и инструменты адаптируются и для других сфер.

## Стандарт качества Guide

С июля 2026 все новые и обновляемые разделы пишутся по единому стандарту:

- Высокая информационная плотность (справочник, а не лёгкая статья)
- Чёткая структура: определение → зачем важно → как применять → ошибки/анти-паттерны → связанные материалы
- Пригодность как корпуса знаний для будущего обучения ИИ-ассистента Райя
- Обязательный факт-чек ключевых утверждений

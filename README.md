# Ассистент Райя — Полноценный путеводитель по рекрутменту + AI-инструментам

**Райя помогает рекрутеру, но не заменяет его полностью.**

---

## О проекте

**Ассистент Райя** — открытый проект из двух частей:

1. **Райя гид** — практический путеводитель по рекрутменту полного цикла (от поиска до онбординга).
2. **Райя инструмент** — полностью **локальные** AI-инструменты (никаких облачных API, соответствие 152-ФЗ).

Основной фокус — IT-рекрутмент, принципы применимы и в других сферах.

**Связь:** [t.me/alexaroff](https://t.me/alexaroff) · [x.com/alexaroff_hr](https://x.com/alexaroff_hr)

## Быстрый старт Tool (локальная транскрипция)

```bash
git clone https://github.com/alexaroff/RAIA.git
cd RAIA && git checkout tool-local-v1
cd tool
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e ".[vad]"
brew install ffmpeg   # если ещё нет

python -m tool.transcription.cli path/to/interview.webm -o ./output -v
```

Подробности: [`tool/README.md`](tool/README.md) и [`docs/INSTALL.md`](docs/INSTALL.md).

## Философия

- AI — помощник, а не замена рекрутеру.
- Данные кандидатов не должны уходить в облако (152-ФЗ).
- Инструмент должен работать уже на 8 ГБ и комфортно масштабироваться.

**Райя помогает человеку, но не заменяет его полностью.**  
Потому что самое важное в рекрутменте — человеческое чутьё, эмпатия и ответственность.

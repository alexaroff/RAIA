# Установка RAIA Tool (Local Only)

**Статус:** черновик. Будет заполнен после выбора финального стека.

## Требования

- macOS (Apple Silicon предпочтительно) или Linux
- Python 3.11+
- FFmpeg
- 8 ГБ ОЗУ минимум (16–32 ГБ рекомендуется)

## Планируемые шаги

1. Клонировать репозиторий и переключиться на ветку `tool-local-v1`
2. Создать виртуальное окружение (рекомендуется `uv`)
3. Установить зависимости
4. Скачать модели (Whisper + GigaChat 3 Lightning GGUF)
5. Запустить UI

Подробности появятся после Фазы 1.

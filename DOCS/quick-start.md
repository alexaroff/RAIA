# Инструкция по работе с RAIA

---

## Шаг 1 — Транскрипция интервью

### Способ 1 — Через локальный Web UI (рекомендуется)

1. Дважды кликни по **RAIA.command** на рабочем столе
2. Автоматически откроется браузер на `http://localhost:7860`
3. Перетащи файл интервью в зону загрузки (поддерживается .webm, .flac, .mp3, .wav)
4. Нажми **▶ Запустить транскрипцию**
5. Дождись результата — транскрипт появится в поле ниже и будет доступен для редактирования
6. Чтобы остановить сервер — закрой окно терминала

> Конвертация .webm → FLAC происходит автоматически внутри UI. VLC и ручная конвертация не нужны.

---

### Способ 2 — Через терминал (резервный)

Откройте терминал и выполните команду:

```bash
cd ~/RAIA && source raia-env/bin/activate && mkdir -p audio && ffmpeg -i audio/interview.webm -ac 1 -ar 16000 -c:a flac audio/interview.flac && whisperx audio/interview.flac --model ~/whisper_models/turbo --language ru --compute_type int8 --output_dir output --batch_size 4 --vad_method silero --output_format srt,txt,json
```

При запуске через терминал поместите файл в папку:
RAIA/audio/interview.webm

---

### Время обработки

В зависимости от длительности интервью:

- 10–15 минут интервью → ~2–5 минут обработки
- 30–60 минут интервью → ~5–20 минут обработки

Тестовая конфигурация: MacBook Air M2, 8 ГБ ОЗУ

---

### Результат транскрипции

После завершения в папке `RAIA/output` появятся файлы:

- `interview.txt` — чистая текстовая расшифровка
- `interview.json` — сегменты с временными метками, используется для анализа через LLM
- `interview.srt` — субтитры с временными метками, подходит для ручной проверки

## Шаг 2 — Разметка ролей

1. Перейди на вкладку **🏷 Разметка ролей** в Web UI
2. Транскрипт подтянется автоматически из вкладки Транскрипция — или вставь вручную
3. Выбери провайдера: **Groq** (рекомендуется, без VPN) или **Gemini** (нужен VPN)
4. Нажми **▶ Разметить роли**
5. Дождись результата — каждая реплика будет помечена как `HR:` или `CAND:`
6. При необходимости отредактируй результат вручную
7. Нажми **💾 Сохранить** — файл сохранится в `output/interview_roles.txt`

# Prompts Library

Все системные промпты для локального LLM хранятся здесь.

Планируемые файлы:
- `role_tagging.txt` — разметка ролей (если LLM-based)
- `hr_report_v1.txt` — основной промпт генерации HR-отчёта
- `hr_report_compact.txt` — короткий вариант
- `competency_extraction.txt`
- `risk_analysis.txt`

Версионирование промптов обязательно.

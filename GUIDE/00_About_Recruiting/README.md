# О профессии рекрутера

Этот раздел — фундаментальная база всего Guide. Здесь собраны ключевые понятия, роли, процессы, метрики, этика и мышление, которые нужны и начинающему, и практикующему рекрутеру.

Материалы написаны как **справочник**: плотно, структурировано, с чёткими определениями, практическими рекомендациями и перекрёстными ссылками. Раздел также служит чистым корпусом знаний для будущего обучения ИИ-ассистента Райя.

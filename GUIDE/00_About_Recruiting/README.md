# Введение в профессию рекрутера

Этот раздел — точка входа для всех, кто хочет понять профессию рекрутера: с нуля или системно.

## Что здесь будет

- Кто такой рекрутер и какую ценность он создаёт для компании
- Полный цикл найма: от заявки до выхода кандидата на работу
- Ключевые метрики: time-to-hire, cost-per-hire, quality of hire
- Роли в найме: рекрутер, HRBP, hiring manager — кто за что отвечает
- Этика профессии и анти-биас практики

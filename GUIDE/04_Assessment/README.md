# Оценка кандидата (Assessment)

Оценка — это перевод впечатлений от интервью в структурированные данные для принятия решения.

## Что здесь будет

- Компетентностный подход: как оценивать, а не угадывать
- Scoring rubrics: оценочные таблицы по уровням
- Тестовые задания и кейсы: как составлять и оценивать
- HR-отчёт для нанимающего менеджера
- Красные флаги: на что обращать внимание
- AI-инструменты для анализа интервью

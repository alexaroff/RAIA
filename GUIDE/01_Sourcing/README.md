# Поиск кандидатов (Sourcing)

Sourcing — это системный процесс поиска и первичного привлечения кандидатов (в первую очередь пассивных), которые не откликаются на вакансии самостоятельно.

Цель сорсинга — не «найти резюме», а создать устойчивый поток релевантных людей, с которыми можно начать диалог и которые имеют реальный шанс закрыть позицию.

Этот раздел — практический справочник по всему циклу поиска: от стратегий и каналов до аутрича, работы с базой и метрик. Материалы написаны с высокой информационной плотностью и служат корпусом знаний для будущего ИИ-ассистента Райя.

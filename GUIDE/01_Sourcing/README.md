# Поиск кандидатов (Sourcing)

Sourcing — это искусство находить нужных людей там, где они есть, и выходить на них так, чтобы они ответили.

## Что здесь будет

- Стратегии поиска: Boolean search, X-Ray, LinkedIn и нишевые платформы
- Работа с пассивными кандидатами
- Холодный аутрич: шаблоны и персонализация
- Работа с базой кандидатов и ATS
- AI-инструменты для сорсинга

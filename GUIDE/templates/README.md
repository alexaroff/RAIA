# Templates — Шаблоны и чек-листы

Готовые к использованию шаблоны для всех этапов найма.

## Что здесь будет

- Шаблоны сообщений кандидатам (первый контакт, follow-up)
- Шаблоны писем: оффер, отказ, обратная связь
- Чек-листы: скрининг, интервью, онбординг
- Оценочные карточки (scorecards)
- Шаблоны HR-отчётов

## Структура

Шаблоны организованы по этапам найма — каждый файл соответствует разделу Guide.

# Проведение интервью (Interviewing)

Интервью — ключевой этап найма. Здесь рекрутер оценивает кандидата, а кандидат оценивает компанию.

## Что здесь будет

- Виды интервью: структурированное, поведенческое, кейсовое
- STAR-метод: теория и практика
- Банки вопросов по IT-специальностям и общим компетенциям
- Как вести заметки во время интервью
- Типичные ошибки интервьюера
- AI-инструменты: транскрипция и подготовка вопросов

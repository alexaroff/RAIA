# Фиксация наблюдений и оценка

**Заметки и оценка** — это то, что превращает интервью из «разговора» в источник сопоставимых данных для решения о найме.

Без качественной фиксации даже идеально проведённое интервью теряет ценность: на debrief остаётся только общее впечатление, а калибровка между интервьюерами становится невозможной.

---

## Зачем нужны структурированные заметки

1. **Снижение bias**  
   Когда есть факты, а не только «мне понравилось», halo- и horn-эффекты слабеют.

2. **Сопоставимость кандидатов**  
   Через 2–3 недели после интервью память искажается. Заметки сохраняют signal.

3. **Качественный debrief**  
   Можно обсуждать конкретные поведения, а не спорить об ощущениях.

4. **Обучение и улучшение процесса**  
   По заметкам видно, какие вопросы работают, а какие дают шум.

5. **Legal defensibility**  
   При необходимости можно показать, на основании каких данных принималось решение.

---

## Как делать заметки во время интервью

### Принципы

- Фиксировать **факты и цитаты**, а не оценки («сильный», «слабый», «крутой»).
- Разделять S-T-A-R хотя бы условно.
- Отмечать, где пришлось сильно probing’ить, а где ответ пришёл сразу полным.
- Оставлять место для post-interview evaluation (не ставить итоговые scores в процессе).

### Практичный формат заметок

```
Вопрос / Компетенция: Ownership

S: ...
T: ...
A: ...
R: ...

Probing notes: пришлось 3 раза уточнять личный вклад
Signal strength: средний → высокий после probing
Red flags / concerns: ...
```

Можно использовать таблицу или просто структурированный текст. Главное — единообразие внутри команды.

### Чего избегать

- Писать только итоговую оценку без фактов.
- Фиксировать интерпретации («явно не командный игрок»).
- Пытаться записать всё дословно (это невозможно и вредно).
- Откладывать заметки «на потом» — память быстро искажается.

## Interview Scorecard

Scorecard на этапе интервью сложнее, чем на скрининге. Он должен покрывать ключевые компетенции и давать место для qualitative comments.

### Минимальная структура

| Компетенция | Оценка (1–5) | Ключевые факты / цитаты | Комментарий |
|-------------|--------------|--------------------------|-------------|
| Ownership | | | |
| Problem Solving | | | |
| Collaboration | | | |
| Technical Depth (если применимо) | | | |
| Communication | | | |
| **Overall Recommendation** | Hire / No Hire / Borderline | | |

### Шкала (пример)

| Балл | Значение |
|------|----------|
| 1 | Значительно ниже ожиданий |
| 2 | Ниже ожиданий |
| 3 | Соответствует ожиданиям уровня роли |
| 4 | Выше ожиданий |
| 5 | Значительно выше ожиданий (редкий сигнал) |

Важно: 3 — это «хороший кандидат на этот уровень», а не «средненький». Многие интервьюеры занижают шкалу.

## Калибровка интервьюеров

Без калибровки scores разных людей несопоставимы.

### Как калибровать

1. **Совместный разбор 2–3 записанных или детально законспектированных интервью**  
   «Почему ты поставил 4, а я 2?»

2. **Якоря для шкалы**  
   Для каждой компетенции заранее прописать, что означает 1, 3 и 5 на примере реальных поведений.

3. **Регулярный debrief после сессий**  
   Не только «берём / не берём», но и «насколько наши оценки совпали и почему».

4. **Тренинг новых интервьюеров**  
   Парное проведение первых 3–5 интервью с опытным коллегой.

## Debrief-процесс

Хороший debrief — это structured discussion, а не голосование по ощущениям.

### Рекомендуемый порядок

1. Каждый интервьюер **сначала** озвучивает свои scores и ключевые факты (без общего recommendation).
2. Обсуждаются расхождения (особенно разница ≥ 2 балла по компетенции).
3. Только после этого — overall recommendation.
4. Фиксируется итоговое решение + что сказать кандидату + риски, если берём.

### Правила debrief

- Сначала данные, потом мнения.
- «Мне понравилось» — не аргумент.
- Один сильный или слабый сигнал не должен полностью перевешивать остальные (если только это не deal-breaker).
- Если данных недостаточно — лучше провести дополнительное интервью, чем гадать.

---

## Типичные ошибки

- Ставить оценки прямо во время интервью (искажает дальнейшее восприятие).
- Писать заметки в стиле «отличный парень, берём».
- Проводить debrief сразу после интервью, пока эмоции горячие, без времени на самостоятельную оценку.
- Игнорировать расхождения в scores («ну примерно одинаково»).
- Не возвращаться к заметкам при принятии финального решения через несколько дней.

---

## Практический чек-лист

- [ ] Есть единый шаблон заметок / scorecard
- [ ] Заметки фиксируют факты и STAR, а не оценки
- [ ] Scores ставятся после интервью, а не во время
- [ ] Интервьюеры калиброваны (хотя бы базово)
- [ ] Debrief начинается с фактов и scores, а не с «берём/не берём»
- [ ] Итоговое решение и обоснование фиксируются

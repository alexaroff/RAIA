# Как фиксировать наблюдения и оценивать

Заметки и оценка — это то, что превращает интервью из обычного разговора в источник понятных данных для решения.

Без нормальной фиксации даже хорошо проведённое интервью быстро теряет ценность: через несколько дней остаётся только общее впечатление, а сравнивать кандидатов и обсуждать их с коллегами становится сложно.

---

## Зачем нужны структурированные заметки

1. Меньше влияния случайных впечатлений и симпатий.
2. Можно сравнивать кандидатов между собой через дни и недели.
3. Обсуждение с другими интервьюерами становится предметным, а не спором об ощущениях.
4. Можно улучшать процесс: видно, какие вопросы дают полезный сигнал, а какие — нет.
5. При необходимости можно объяснить, на основании чего было принято решение.

---

## Как делать заметки во время интервью

**Главные принципы:**
- Фиксируйте факты и конкретные формулировки, а не оценки («сильный», «слабый», «крутой»).
- Старайтесь отмечать Situation – Task – Action – Result.
- Отмечайте, где пришлось сильно уточнять, а где ответ сразу был полным.
- Итоговые баллы лучше ставить после интервью, а не во время.

**Простой формат:**

```
Вопрос / Качество: Ответственность

Ситуация: ...
Задача: ...
Действия: ...
Результат: ...

Уточнения: пришлось 3 раза спрашивать про личный вклад
Насколько сильный сигнал: средний → стал выше после уточнений
Настораживающие моменты: ...
```

Можно использовать таблицу или просто структурированный текст. Главное — чтобы внутри команды формат был похожим.

**Чего избегать:**
- Писать только итоговую оценку без фактов.
- Фиксировать интерпретации («явно не командный игрок»).
- Пытаться записать всё дословно.
- Откладывать заметки «на потом».

---

## Оценочная таблица (scorecard)

На этапе интервью таблица обычно подробнее, чем на скрининге.

**Минимальный набор колонок:**

| Качество | Оценка (1–5) | Ключевые факты / формулировки | Комментарий |
|----------|--------------|-------------------------------|-------------|
| Ответственность | | | |
| Решение проблем | | | |
| Работа в команде | | | |
| Коммуникация | | | |
| Техническая глубина (если нужно) | | | |
| **Итоговая рекомендация** | Берём / Не берём / На границе | | |

**Пример шкалы:**

| Балл | Значение |
|------|----------|
| 1 | Значительно ниже ожиданий |
| 2 | Ниже ожиданий |
| 3 | Соответствует ожиданиям уровня роли |
| 4 | Выше ожиданий |
| 5 | Значительно выше ожиданий (редкий сигнал) |

Важно: 3 — это «хороший кандидат на этот уровень», а не «средненький». Многие интервьюеры занижают шкалу.

## Как калибровать интервьюеров

Без калибровки оценки разных людей плохо сопоставимы.

Что помогает:
1. Совместно разобрать 2–3 интервью и сравнить, почему кто-то поставил 4, а кто-то 2.
2. Заранее прописать, что означает 1, 3 и 5 по каждой важной компетенции на конкретных примерах поведения.
3. После сессий не только решать «берём / не берём», но и смотреть, насколько оценки совпали.
4. Новых интервьюеров первые несколько раз лучше проводить вместе с более опытным коллегой.

---

## Как проводить обсуждение после интервью (debrief)

Хорошее обсуждение — это разбор данных, а не голосование по ощущениям.

**Рекомендуемый порядок:**
1. Каждый сначала озвучивает свои баллы и ключевые факты (без общей рекомендации).
2. Обсуждаются расхождения (особенно если разница 2 балла и больше).
3. Только после этого — общая рекомендация.
4. Фиксируется решение, что сказать кандидату и какие есть риски, если берём.

**Правила:**
- Сначала данные, потом мнения.
- «Мне понравилось» — не аргумент.
- Один яркий сигнал не должен полностью перевешивать остальные данные (если только это не жёсткий стоп-фактор).
- Если данных недостаточно — лучше провести ещё одну встречу, чем гадать.

---

## Частые ошибки

- Ставить итоговые оценки прямо во время интервью.
- Писать заметки в стиле «отличный парень, берём».
- Начинать обсуждение сразу с «берём / не берём».
- Игнорировать расхождения в оценках.
- Не возвращаться к заметкам, когда решение принимается через несколько дней.

---

## Короткий чек-лист

- [ ] Есть единый шаблон заметок и оценочной таблицы
- [ ] Заметки фиксируют факты, а не только впечатления
- [ ] Баллы ставятся после интервью
- [ ] Интервьюеры хотя бы базово откалиброваны
- [ ] Обсуждение начинается с фактов и баллов, а не с готового решения
- [ ] Итоговое решение и его обоснование фиксируются
